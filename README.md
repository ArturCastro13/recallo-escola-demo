# Recallo · demonstração para escolas

Protótipo navegável com dados fictícios, publicado em https://escola.recallo.com.br.

- `/aluno` — experiência do aluno (Hoje, Atividades, Minha evolução, Perfil)
- `/professor` — visão do professor (fila de feedback, atividades, alunos)
- `/escola` — painel da escola (participação, aprendizagem e acompanhamento)

Este repositório contém apenas o pacote compilado da demonstração. Não há backend: as respostas ficam na sessão do navegador e não são enviadas a ninguém. Artur, João, Marina e a Escola Horizonte são fictícios.
